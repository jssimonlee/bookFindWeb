# 화성시 도서관 책 찾기

ISBN 또는 책 제목으로 화성시 도서관 소장 자료를 확인하는 Cloudflare Pages 웹 애플리케이션입니다. 도서 구매 전에 이미 소장 중이거나 최근 구매한 책인지 확인하는 용도로 사용합니다.

## 검색 방식

1. 화성시 도서관 홈페이지에서 선택한 도서관의 소장 자료를 먼저 검색합니다.
2. **사서제한 도서까지 함께 검색**을 켠 경우에만 홈페이지에 없는 ISBN을 브라우저의 최근 구매 목록에서 확인합니다.
3. 이어서 정보나루에서 내려받아 등록한 월간 장서 파일을 확인합니다.
4. 월간 장서 파일에만 있는 책은 **사서제한 추정**으로 표시합니다. 토글이 꺼져 있으면 홈페이지 결과만 사용합니다.

도서관정보나루 API는 사용하지 않습니다. 월간 장서와 최근 구매 파일은 서버로 전송하지 않고 현재 브라우저의 IndexedDB에만 저장합니다.

## 제공 기능

- ISBN 10자리·13자리 또는 책 제목 검색
- 줄 단위 다중 검색: 한 번에 최대 200건, 서버 요청은 20건씩 분할
- 화성시 도서관 32개관 및 전체도서관 선택
- 도서관별 정보나루 월간 장서 CSV/XLSX 등록
- 여러 최근 구매 CSV/XLSX 누적 등록 및 개별 삭제
- 월간 장서의 최신 `등록일자`를 기준일로 안내
- 동일 ISBN의 복수 등록번호 수집 및 누락 시 서지정보 보완 조회
- 소장·최근 구매·사서제한 추정·미소장·오류 상태 구분
- 실제 `.xlsx` 검색 결과 다운로드
- 선택 도서관과 파일 데이터를 브라우저에 저장

절판 검색, 네이버 도서 API, 도서관정보나루 API, Turnstile 기능은 포함하지 않습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```powershell
npm install
npm run dev
```

기본 주소는 `http://localhost:8788`입니다. 외부 API 키나 별도 환경 변수는 필요하지 않습니다.

```powershell
npm test
```

## Cloudflare Pages 배포

Cloudflare Pages 프로젝트를 GitHub 저장소에 연결할 경우 다음과 같이 설정합니다.

1. Production branch: `main`
2. Framework preset: `None`
3. Build command: 비워 두기
4. Build output directory: `public`
5. Root directory: 저장소 최상위 폴더

`functions` 폴더는 Cloudflare Pages Functions로 자동 배포됩니다. 별도의 API 키나 Turnstile 환경 변수는 설정하지 않아도 됩니다.

## 무료 플랜에 맞춘 제한

- 정적 파일은 Pages Functions를 거치지 않습니다.
- `/api/*` 요청만 Functions로 처리합니다.
- 요청당 검색어는 20개이며 화면에서 최대 200개를 자동 분할합니다.
- 화성시 도서관 검색은 12초 타임아웃을 적용합니다.
- IP별 분당 30회의 기본 요청 제한을 둡니다.
- 별도 데이터베이스, KV, 유료 서비스는 사용하지 않습니다.

## 결과 상태

| 상태 | 의미 |
|---|---|
| 소장 | 화성시 도서관 홈페이지에서 확인됨 |
| 최근 구매 확인 | 등록한 최근 구매 목록에서 확인됨 |
| 사서제한 추정 | 홈페이지에는 없지만 등록한 월간 장서 파일에는 있음 |
| 미소장 | 홈페이지와 등록 파일 모두에서 확인되지 않음 |
| 검색 오류 | 화성시 도서관 홈페이지 연결 또는 응답 처리 실패 |

## 주요 파일

```text
public/                 정적 웹 화면, 파일 파서, Excel 생성 코드
functions/api/          Cloudflare Pages Functions API
server/libraries.js     화성시 도서관 코드·별칭 목록
server/search.js        화성시 검색 및 등록번호 보완 조회
test/                   파서·검색 흐름·XLSX 테스트
wrangler.jsonc          Cloudflare 로컬/배포 설정
```
