도서 구입 전, 화성시 도서관에 이미 있는 책인지 확인해 보세요

도서 구매 전에 ISBN으로 화성시 도서관의 소장 여부를 한 번에 확인할 수 있는 무료 웹 도구를 만들었습니다.

이미 도서관에 소장된 책을 구매 대상에서 제외하거나, 여러 권의 구입 예정 도서를 한꺼번에 검토할 때 사용할 수 있습니다.

사이트 바로가기
https://hsbook.pages.dev/

────────────────────
주요 기능
────────────────────

• ISBN을 최대 500권까지 한 번에 검색
• 전체도서관 또는 개별 도서관 선택
• ISBN 앞뒤 공백, 탭, 하이픈, 엑셀 복사 시 붙는 따옴표 자동 정리
• 소장, 최근 구매, 사서제한 추정, 미소장 결과 구분
• 등록번호와 청구기호 등 소장 정보 확인
• 검색 결과를 순번이 포함된 Excel 파일로 다운로드
• 회원가입 없이 사용

────────────────────
기본 사용법
────────────────────

1. 확인하려는 ISBN을 한 줄에 한 권씩 붙여 넣습니다.

2. 확인할 도서관을 선택합니다. 여러 도서관을 한꺼번에 확인하려면 전체도서관을 선택합니다.

3. 소장 여부 확인하기 버튼을 누릅니다.

4. 검색 결과에서 상태와 서명, 등록번호, 청구기호 등을 확인합니다.

5. 필요한 경우 Excel 다운로드 버튼으로 결과를 저장합니다.

엑셀에서 ISBN 열을 그대로 복사해도 됩니다. 앞뒤 공백이나 탭, 하이픈, 큰따옴표 등은 자동으로 정리됩니다.

────────────────────
사서제한 도서까지 함께 검색하려면
────────────────────

공개 도서관 홈페이지 검색에 나타나지 않는 자료도 확인하고 싶다면 개별 도서관을 선택한 뒤 사서제한 도서까지 함께 검색을 켭니다.

도서관정보나루에서 해당 도서관의 최신 월간 장서 파일을 내려받아 등록하면 홈페이지 검색 결과와 함께 비교합니다. 월간 데이터 작성 이후 구매했지만 아직 배가되지 않은 책은 최근 구매 CSV 또는 XLSX 파일로 추가할 수 있습니다.

검색 결과에서 사서제한 추정은 공개 홈페이지에서는 보이지 않지만 등록한 월간 장서 데이터에는 있는 책을 뜻합니다. 실제 소장 상태와 다를 수 있으므로 필요한 경우 도서관 홈페이지에서 다시 확인해 주세요.
